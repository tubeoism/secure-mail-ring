## Goal
A buildable, testable repository skeleton that every later card can build on: `npm run verify` is green, CI runs it, and the ownership path guard and i18n key check exist.

## Allowed paths
Lead-owned paths only (`AGENTS.md` §2), plus `docs/tasks/**`.

## Requirements
1. npm workspaces with `packages/core` (`@smr/core`), TypeScript `strict`, ESLint (flat config), Prettier, Vitest.
2. `npm run verify` = lint + format check + typecheck + tests + path guard + i18n key check.
3. CI workflow runs `npm ci` and `npm run verify` on every PR and on `main`.
4. Directory skeleton from plan §9 with ownership-correct placeholders.
5. Lint rules enforce `AGENTS.md` §6.4: no `console`, `eval`, `innerHTML`, `dangerouslySetInnerHTML`, `any`.

## Acceptance criteria
- [x] AC-1 `npm run verify` passes on a clean checkout.
- [x] AC-2 Path guard fails an `ag/*` diff that touches lead-owned paths (negative test run locally; unit test in `scripts/guards.test.mjs`).
- [x] AC-3 i18n check reports keys missing from a locale (`scripts/guards.test.mjs`).
- [x] AC-4 `packages/core` has a coverage gate (lines ≥ 90 %).
- [x] AC-5 CI workflow present at `.github/workflows/ci.yml`.

## Decisions and deviations
- **Platform:** Office Web Add-in per plan v1.0 (PO confirmed in thread). COM .NET 10 is not used (plan §4.4).
- **Not run:** `yo office`. It is interactive and generates demo code that would be deleted. The skeleton is hand-written to the plan's layout.
- **Deferred dependencies** (added by the card that needs them, to keep the lockfile small): webpack, React, Fluent UI, `fflate`, `valibot`, `office-addin-mock`, `fast-check` (CL-03), StrykerJS (before the first core PR), `javascript-obfuscator` (CL-09).
- **Manifest:** placeholder only; the real manifest is CL-06.
- **Mutation testing** is not wired yet; `CLAUDE.md` requires it for core PRs, so it lands with CL-03.

## Out of scope
Contracts (CL-02), spikes (CL-01), hosting, real manifest.
