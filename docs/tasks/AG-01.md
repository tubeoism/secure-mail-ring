## Goal
The PO can click through every task-pane screen in a normal browser, with realistic sample data, and approve the UX before any screen is wired to real storage or Outlook.

## Allowed paths
- `src/taskpane/**`
- `src/shared/i18n/locales/**`
- `docs/tasks/evidence/AG-01/**`
- `docs/tasks/AG-01.md` (Status and Notes only)

## Inputs (read-only)
- Fixtures: `src/shared/contracts/fixtures/rings.json`, `findings.json`, `settings.json`
- `MockOfficeAdapter`, `MockStorageAdapter` from `src/shared/office` and `src/shared/storage`
- Types: `Ring`, `Finding`, `PolicyMode`, `Settings` from `src/shared/contracts`
- i18n: `t(key)` and the key list in `src/shared/contracts/i18nKeys.ts`

## Requirements
1. Screens, reachable from a simple navigation: **Ring list**, **Ring editor** (tabs: Members · Subject tag · Attachments · Ordering · Field rules · Policy), **Settings**, **Compose pane** (ring picker + "Sort now"), **Acknowledge pane**, **Export / share**, **Import** (paste + diff preview).
2. Every screen renders from fixtures through the mock adapters — no hard-coded sample data in components.
3. Fluent UI React v9 components only; follow Outlook task-pane look.
4. Language switch `vi` / `en` works on every screen.
5. Editing in the prototype may update in-memory mock state only; nothing is persisted.
6. Runs with `npm run dev:taskpane` in a desktop browser; no Outlook required.

## Acceptance criteria
- [ ] AC-1 Every screen in requirement 1 is reachable within two clicks from the ring list.
- [ ] AC-2 With the fixture set, the ring list shows all fixture rings, and the ring editor shows every field of the first fixture ring.
- [ ] AC-3 Layout has no horizontal scroll and no clipped controls at 320 px and at 450 px width.
- [ ] AC-4 Every screen is fully operable by keyboard alone (Tab / Shift+Tab / Enter / Space / Esc).
- [ ] AC-5 Switching to `en` and back to `vi` changes every visible string; no raw keys are shown.
- [ ] AC-6 Severity in the Acknowledge pane is shown by icon + text, not colour alone.
- [ ] AC-7 Component tests render each screen with fixtures and assert its key elements; `npm run verify` is green.
- [ ] AC-8 Screenshots of every screen, in `vi`, at 320 px, saved under `docs/tasks/evidence/AG-01/`.

## Edge cases
- Ring list empty (use the empty fixture variant).
- A ring with 50+ members and a very long name.
- A Vietnamese string much longer than its English equivalent.

## Out of scope
- Real persistence, validation logic, Office.js, Smart Alerts behaviour — all lead tasks.
- Final visual polish; this is for UX approval.
